# Sistema de Lavanderia

Projeto de Programação Orientada a Objetos (POO).
Alunas: Dhenifer, Eduarda Jackeline 

## Classes

- Cliente
- Roupa
- Lavagem
- MaquinaLavar
- Pagamento
- Lavanderia

## Objetivo

Criar um sistema simples para cadastrar clientes e roupas, registrar lavagens, controlar máquinas e registrar pagamentos.

## Funcionalidades

- Cadastro de clientes
- Cadastro de roupas
- Registro de lavagens
- Controle das máquinas de lavar
- Acompanhamento do status da lavagem
- Registro de pagamentos

## Tecnologias

- Python
- Programação Orientada a Objetos (POO)
